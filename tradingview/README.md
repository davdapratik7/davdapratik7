# Levels + 50% Midpoint (OI Plan) — TradingView indicator

1. TradingView → Pine Editor → paste `levels_50pct_oi.pine` → *Add to chart*.
2. Put your hand-marked levels in **Manual levels** (e.g. `22185,24985`).
3. Daily chart: green = extreme bullish, red = extreme bearish, black dashed = 50%.
4. 15m chart: blue/orange = nearest 15m levels, purple = inner 50%.
5. BUY/SELL labels show T1/T2 (next levels). Tick the **OI** toggles after checking
   the option chain — Pine cannot read OI.
